# HackerNews

Flutter project to read articles from `https://news.ycombinator.com`

## OpenSpec Setup

This project uses [OpenSpec](https://github.com/Fission-AI/OpenSpec) for spec-driven
development with AI coding assistants. The `openspec/` directory (specs and change
proposals) is committed, but the generated Claude commands and skills under
`.claude/commands/opsx/` and `.claude/skills/openspec-*/` are gitignored, since they're
regenerated by the CLI and would otherwise drift out of sync every time someone upgrades it.

To set them up locally:

```sh
# Install the CLI globally
npm install -g @fission-ai/openspec@latest

# First time only: initialize OpenSpec for Claude in this repo
openspec init --tools claude --force

# Any time after that (e.g. after upgrading the CLI): regenerate commands/skills
openspec update --force
```

Project-specific OpenSpec configuration (tech stack context, per-artifact rules) lives in
`openspec/config.yaml`, which **is** committed and safe to edit by hand.
